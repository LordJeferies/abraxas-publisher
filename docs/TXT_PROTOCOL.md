# TXT Protocol

Ejemplo:

```text
PLATFORM: instagram
ACCOUNT: joc_instagram
TYPE: reel
DATE: 2026-10-06
TIME: 19:00

COPY:
Texto del contenido.
```

- `DATE` + `TIME` => target `PRECALENDARIZED`.
- Sin fecha/hora => bandeja `Sin calendarizar`.
- `CORRECCION.txt` queda reservado a ABRAXAS y el scanner lo ignora como target.
- Los tokens nunca se guardan en TXT.
