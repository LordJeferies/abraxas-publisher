Publisher Desktop

Instala la app nativa en ~/Applications y crea acceso en el Escritorio.

Dependencias

Comprueba Homebrew, Node, Rust/Cargo, Git y FFmpeg; instala lo que falte.

MCP incluido

Compila, instala y prueba el bridge MCP en una ruta estable del usuario.

Cómo instalar

  1. Pulsa Descargar instalador para Mac.
  2. Abre ABRAXAS_PUBLISHER_INSTALL.command desde Descargas.
  3. macOS abrirá Terminal. Escribe la clave de instalación.
  4. Si macOS pide herramientas de Apple o contraseña de administrador, complétalo.
  5. Al terminar, Publisher se abrirá automáticamente.
La clave funciona como control de conveniencia para el instalador. Esta página y el instalador son públicos, así que no debe considerarse un mecanismo de seguridad para secretos o datos sensibles.
